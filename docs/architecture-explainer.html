1 · Research pipeline (offline, one-time)

Public-domain sources

Bulfinch, Frazer, sacred-texts, Gutenberg, HathiTrust… stored verbatim in data/raw/

Batch curation

data/raw/batch-*.json — texts researched with source URL, license, coordinates, sensitivity flag, evidence-tagged passages

Corpus builder

scripts/01_build_corpus.py validates ids, coords, sensitivity; rejects restricted: true

↓ merges into

App corpus (frozen)

src/data/texts.json — 5,494 texts · 39 traditions  ·  src/data/motifs.json — 270 motif tags  ·  src/data/characters.json — 153 fictional figures / 41 traditions

Pre-computed vectors

scripts/embed_corpus.mjs → public/semantic-embeddings.json (10.8 MB, one 384-dim MiniLM vector per story) + scripts/04_semantic_cache.py → public/semantic-cache.json (similarity matrix + 2D/3D map projection from those vectors) — computed at build time, never in the browser

2 · Runtime (static site, Cloudflare Pages)

React SPA (Vite build → dist/)

src/lib/search.js TF-IDF + per-story MiniLM embeddings power all views — search, Compare, Network parallels and the Embedding Map all read the same vectors. No server, no database, no runtime writes.
